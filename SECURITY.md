# Security policy

## Supported versions

| Version | Supported |
|---|---|
| Latest (`main` / `v1.0.x`) | Yes |
| Older snapshots | No |

Only the latest state on `main` receives fixes.

## Report a vulnerability

Do not report security problems in public issues or pull requests.

Report them privately through [GitHub private vulnerability reporting](https://github.com/andrew-abdelmalak/4-dof-service-manipulator/security/advisories/new).

Include:

- The affected commit or release tag
- Steps to reproduce or a proof of concept
- Expected impact (such as unsafe hardware commands or serial injection)

You will receive a response as soon as a maintainer reviews the private advisory.
